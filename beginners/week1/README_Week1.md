# ☕ Java Learning – Week 1 (Fundamentals & Mini Project)

This repository contains all exercises and projects from my **first week of learning Java**.  
I focused on the essential building blocks of the language: syntax, logic, conditions, loops, arrays, lists, and methods.  
By the end of this week, I completed a small **Student Score Management** project.

---

## 📅 **Day-by-Day Learning Plan**

### 🔹 Day 1–2: Environment & Basics
**Learn:**
- Installing JDK and IntelliJ IDEA / Eclipse  
- Writing the first Java program (`Hello World`)  
- Understanding `class`, `main`, and `System.out.println()`  
- Data types: `int`, `double`, `boolean`, `String`  
- Operators: `+`, `-`, `*`, `/`, `%`, `++`, `--`

**Practice:**
- A program that takes two numbers and prints their sum, subtraction, and multiplication.  
- Practice getting user input with `Scanner`.

---

### 🔹 Day 3: Conditional Statements
**Learn:**
- `if`, `else if`, `else`  
- `switch` statements  
- Comparison operators (`==`, `!=`, `<`, `>`, `<=`, `>=`)

**Practice:**
- Program that takes a student’s grade and prints if they passed or failed.  
- Program that checks if a number is even or odd.

---

### 🔹 Day 4: Loops
**Learn:**
- `for`, `while`, and `do-while` loops  
- Loop counters and iteration logic  

**Practice:**
- Program that prints the multiplication table (1–10).  
- Program that calculates the sum of numbers from 1 to n.

---

### 🔹 Day 5: Arrays and ArrayList
**Learn:**
- Declaring arrays (`int[] numbers = new int[5];`)  
- Traversing arrays with loops  
- Using `ArrayList` for dynamic data

**Practice:**
- Program that takes 5 grades and calculates the average.  
- Store grades in an `ArrayList` and find the highest grade.

---

### 🔹 Day 6: Methods (Functions)
**Learn:**
- Defining methods (`public static void sayHello()`)  
- Parameters and return values  
- Method calls and reusability

**Practice:**
- Method that checks if a number is prime.  
- Method that calculates the average of three numbers.

---

### 🔹 Day 7: Mini Project – Student Score Management

💻 **Project Name:** `MiniProject_StudentScores.java`

**Features:**
- Simple text-based menu  
- Add, view, and delete student scores  
- Store scores in an `ArrayList`  
- Display the highest and lowest scores  

**Concepts used:**
- Loops  
- Conditions  
- Lists  
- Methods  

---

## ⚙️ How to Run

1. Open project in IntelliJ IDEA, Eclipse, or VS Code.  
2. Compile and run:
   ```bash
   javac FileName.java
   java FileName
   ```

By the end of Week 1:
- I can write and understand basic Java programs.  
- I can use loops, arrays, and conditions effectively.
