# Week 2 -- Object-Oriented Programming (OOP) in Java

This folder contains all exercises, examples, and the final mini‑project
for **Week 2**, focusing on Java Object-Oriented Programming concepts.

------------------------------------------------------------------------

## 🔹 Topics Covered

### **1. Classes & Objects**

-   Creating classes and objects
-   Fields and behaviors
-   Real‑world modeling (Books, EBooks, Library)

------------------------------------------------------------------------

### **2. Constructors**

-   Purpose of constructors\
-   Initializing object state\
-   Constructor overloading\
-   Using `super()` in subclasses

------------------------------------------------------------------------

### **3. Encapsulation**

-   `private` fields\
-   `getter` and `setter` methods\
-   Input validation inside setters\
-   Clean and safe object design

------------------------------------------------------------------------

### **4. Inheritance**

-   `extends` keyword\
-   Parent class (Book)\
-   Child classes (PrintBook, EBook)

------------------------------------------------------------------------

### **5. Polymorphism**

-   Overriding methods (`printDetails()`)\
-   Treating different objects (Book/EBook) as one type\
-   Using lists of `Book` references to store multiple book types

------------------------------------------------------------------------

### **6. Abstraction**

-   Creating an **abstract class Book**
-   Abstract methods (e.g., `printDetails()`)
-   Shared features for all book types\
-   Enforcing implementation in subclasses

------------------------------------------------------------------------

### **7. Static Members**

-   `static int totalBooks` to count all created books\
-   `static` method `getTotalBooks()`\
-   Understanding class‑level vs object‑level data

------------------------------------------------------------------------

## 📘 Final Mini Project -- Library Management (OOP Version)

A console‑based library app where the user can:

### **Menu**

1.  Add Printed Book\
2.  Add E‑Book\
3.  Show All Books\
4.  Show Total Number of Books\
5.  Exit

### **Features Included**

-   Abstract `Book` class\
-   Two subclasses: `PrintBook`, `EBook`\
-   Polymorphic book list (`ArrayList<Book>`)\
-   Encapsulation with getters/setters\
-   Constructor usage\
-   Overriding methods\
-   Static variable for counting books\
-   Input handling
